# Nassi Mandalas - Portfolio

A responsive web presentation of Nassi Mandalas' 2026 creative engineering portfolio.

## Privacy status

- Repository visibility: private
- GitHub Pages: disabled
- Publishing workflow: manual only

The site is intentionally not public. When publication is approved, enable GitHub Pages with GitHub Actions as the source, then run the **Publish portfolio to GitHub Pages** workflow.

## Local preview

```bash
npm install
npm run dev
```

Open the local address shown in the terminal.

## Production build

```bash
npm run build
```

The site uses a static export in `dist/client` so it can be published on GitHub Pages when approved.

## Source material

The site's project imagery and claims come from `NassiMandalas-Portfolio.pdf`. The original PDF is included as a downloadable portfolio.
